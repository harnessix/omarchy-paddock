- New: protected windows on Omarchy. Each window that shows a sandbox gets a border: app windows, the display of window mode, and now the terminal window of a terminal run. The border is sage green when the sandbox reaches the network only through paddock's proxy, and amber for a wider network. After a run ends, its terminal window gets its own border back. A badge on the focused protected window shows `paddock · <pasture or harness> · <network> · <age>`, and a click opens the sandbox in the bar panel. The bar widget shows a shield with the count of protected windows, and a panel list focuses each one.
- Changed: `paddock windows` lists terminal windows and window mode displays too. `--json` adds `kind`, `level`, `badge`, `title`, `focused` and the geometry. `--focus ADDRESS` focuses one protected window.
