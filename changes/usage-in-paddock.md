- Changed: The Omarchy agents panel's `omarchy-agent-usage-update` runs as a whole in a usage box for every agent. Each harness folder there is one read-only tree of the host folder and the same folder of every non-isolated sandbox home, each login file is the newest copy across the host and the sandbox homes (and the keeper's copy for Codex), the session bus and host keyring are hidden, and network traffic goes through paddock's proxy to the listed endpoints only. If the box cannot start, the command does not run on the host.
- New: `paddock shims install --scope omarchy-agent` also writes a mise wrapper for `omarchy-agent-usage-update`. `paddock shims remove` takes it out.
- Removed: The per-agent `--except` handling and separate collector sandboxes for Claude Code, Grok Build and Codex are gone. Codex and Grok Build no longer copy new sessions back to the home at exit.
