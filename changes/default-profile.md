- New: `paddock run HARNESS --profile default` starts the harness with a private snapshot of its own host data (conversations, settings, plugins) in the sandbox home. The run changes only the snapshot, paddock prints a summary of the changes at the end and removes the snapshot, and the host is never written. The profiles of claude, codex and grok name their data roots in `[state] data`, and `[profiles.NAME] data` in the user configuration adds more. bwrap only.
