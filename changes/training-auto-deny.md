- New: `[privacy] training = "deny" | "manual" | "vendor"` in the user configuration. With the default `deny`, paddock unchecks the training opt-in in a harness's setup screen and presses [Done], by exact rules of the built-in profile. The first rule is agy 1.4's "Terms of Service & Data Use". A screen that differs, a resize or a user key stops it. The audit log gets the rule, the keys and the outcome.
